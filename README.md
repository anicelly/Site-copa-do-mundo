# ⚽ Copa do Mundo 2026

Projeto web desenvolvido em HTML, CSS e JavaScript inspirado no universo da Copa do Mundo 2026 e no visual moderno dos jogos EA FC/FIFA.

---

# 🌍 Sobre o Projeto

O site apresenta:

- ⭐ As principais estrelas da Copa do Mundo 2026
- ❌ Jogadores conhecidos que ficaram fora da Copa
- 🏆 Seleções favoritas ao título
- 🎮 Visual inspirado em videogames de futebol
- 📱 Layout responsivo e moderno

---

# 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
